# 팀 촬영 목록 — 웹에 없어서 직접 찍어야 하는 장면들

> 실기를 돌릴 건물에서 연출 촬영 (측정-배치 환경 일치 이점 + 라이선스 문제 0).
> 스마트폰 가로, 복도/로비의 로봇 시점 높이(0.5~1.2m)로. 같은 연출을 2~3 각도에서.
> 검수가 진행되며 갱신됨 (2026-08-03 기준).

| 타입 | 필요 | 연출 방법 |
|---|---|---|
| tipped_bin (넘어진 쓰레기통) | ~10장 | 쓰레기통 눕히고 내용물 일부 쏟기 — 2~3곳에서 |
| fallen_sign (쓰러진 입간판) | ~12장 (웹 수집분 전멸 — 촬영 100%) | 입간판·배너 눕히기 |
| fallen_object (떨어진 벽부착물) | ~10장 | 액자·게시판·시계 떼서 바닥에 눕히기 (벽의 빈 자리가 같이 보이면 최고) |
| fallen_papers (떨어진 유인물) | ~8장 | 유인물 몇 장 복도에 흩뿌리기 — 가장 쉬움 (1분) |
| (검수 진행에 따라 추가 가능) | | |
