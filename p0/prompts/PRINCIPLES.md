## 원칙 12 (요약 — 근거·적용처)

1. **답은 열거된 선택지에서 한 글자로** — 자유 서술 생성 금지. (SayCan 생성 67%→채점 84%;
   KnowNo 객관식; 우리 실측 "사고 유도=토큰 소진"과 동방향) → ①②③ 공통
2. **예시는 형식만, 내용은 비운다** — 물체·능력 예시 금지. (Code as Policies "예시가 추상화
   수준을 앵커링"; **POPE**: 물체 이름을 대기만 해도 "있다" 쏠림; 멀티모달 few-shot은 예시 답
   베끼기 — 전부 우리 닻내림 실측의 문헌 대응) → ①에서 특히
3. **관측 사실 주입은 안전, 지어낸 예시는 금지** — 경계선. (Inner Monologue 장면 서술 24→90%대) → ②③
4. **헌법(절대)과 확신(조절)은 별개 문장** — 섞으면 둘 다 약해짐. (Grounded Decoding의
   하드 게이트/소프트 가중 이원화) → ①②
5. **제약은 긍정형 행동으로** — "개입하지 마라" ✗ → "기록만 하라" ✓. (부정문 처리 실패는
   계보 공통 보고; 우리 헌법 24/24 일반화의 설명) → 전 문안
6. **모델이 실측상 잘 아는 어휘로 부른다** — 능력 이름은 단위·형식 내장 관례 명명. (CaP) → ②
7. **VLM은 "어느 능력이 유용한가"만, "지금 되는가"는 규칙·센서·③이** — 서술만으론 능력이
   안 지켜지므로 검증 단계 분리. (GD 비접지 19~28% vs 접지 41~50%) → 체계 전체
8. **확신은 "100개 중 몇 개" 빈도 프레임 + 몰림 금지 명시** — 말로 받는 확신이 로짓보다 보정
   좋음(RLHF 모델 ECE 상대 −50%, Tian). 80~100·5의 배수 몰림은 보편 현상(Xiong) → ①②
9. **다수결의 재료는 사고가 아니라 관측** — 반복 관측마다 ①을 다시 받아 일치율을 두 번째
   확신 지표로. 기권 신호로는 일치율이 자기보고 확신보다 신뢰됨(Cole EMNLP23) → ①
10. **"E: 해당 없음" 선택지 상설** + 추후 순찰 로그 ~400건으로 확신 문턱을 통계 보증으로 승격
    (KnowNo — 논문 용어로는 conformal prediction) → ①②
11. **문안별 능력 목록은 최소 부분집합만** — 전수 열거는 토큰 113.7배(GD Table 4).
    ①은 능력 목록을 아예 싣지 않음 → ②
12. **검증은 싼 이진 게이트 상시 + 실패 시에만 실패 코드 한 줄** (접근불가/대상불일치/능력부족)
    — 자유 반성문은 8B에서 불가(Reflexion 자인). 재시도 결정은 규칙 → ③

**추가 확정 사항** (원칙 반영):
- 역할 문구에 정확도 기대 걸지 않기 — 역할문 효과 없음(162종 대규모, EMNLP24). 형식·어조
  고정용 최소 유지. 역할문에 "신중히 따져보라"류 사고 유발 어휘 금지 (역할몰입의 이득 경로가
  사고 유발이라 think-off 체계에선 역효과 위험).
- 판정 지시·스키마는 문안 **맨 끝** 배치 (긴 입력에서 끝 위치가 최선 — ACL24).
- JSON 강제는 판정(분류)형이라 득 (분류형 41→60% 개선 실증). 스키마는 평면·단순하게
  (엔진별 지원 편차). 스키마를 문안 본문에 반드시 명시.
- think 비활성은 지연 때문만이 아니라 **과제 성질상 옳음** — 지각 판정은 사고가 오히려 해
  (CoT 이득은 수학·기호 한정, ICLR25 메타분석; 시각 재인은 CoT로 −36%p 사례).
